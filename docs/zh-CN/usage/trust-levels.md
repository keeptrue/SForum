# 信任等级

[← 使用说明](./README.md)

> **状态：已生效（2026-11-11 复核）。** 阶梯判定（1–8 档，默认 5 档）、阈值策略、请求装载期的合并、
> 产品开关、后台「论坛管理 → 信任等级」页（等级总览 / 档位管理 / 门槛设置 / 能力解锁四个分区）、
> 公开等级查询接口、资料页等级卡都已落地并接线：
> **保存会立即改变等级判定与分档限额**。能力解锁（earnable）默认关闭，需运营按档勾选，
> 见「开启能力解锁」。另有 **2 个键由系统基线门控**：默认安装下 TL0 不生效、TL1 起生效，
> 见「两个键由等级门控」。

## 一句话

角色权限回答「管理员给了你什么」，信任等级回答「你在这里做过多少」。后者只解锁**已经
存在**的权限，不会凭空造出新能力。**唯一的减法**：TL0 阶段系统会把两个基线键（发主题、
上传附件）扣下，TL1 起自动恢复——那不是角色被改，见「两个键由等级门控」。

## 它不是什么

- **不是第二套权限系统。** 裁决仍然只有一个入口（`Can()`），信任等级是装载期并进去的
  一个附加来源，不是并列的第二套检查。
- **不是徽章。** 徽章只展示，永远不给能力；信任等级反过来只给能力，不展示成荣誉。
- **不是审批流程。** 没有提名、没有人工晋升，纯规则、纯计算。

## 阶梯：1–8 档，默认 5 档

**TL0 是固定档**：它是新成员档，不在「档位管理」里，不能改名、不能停用。可配置的是 TL1
起的档位；默认安装启用 4 个（合计 5 档），你可以按站点需要增减到 1–8 档。

| 档位 | 默认名称 | 定位 |
| --- | --- | --- |
| TL0 | 新用户 | 刚注册，等同今天的「新人限制」 |
| TL1 | 正式用户 | 已过信任期 |
| TL2 | 常驻用户 | 有稳定产出 |
| TL3 | 资深用户 | 长期贡献 |
| TL4 | 领袖 | 站点核心 |

上表是**默认安装**的样子。档位可以增删、插序、改名、换图标，见「增加、减少与插序」与
「命名与图标」。

### 默认阈值

判定是「全部指标同时达到」才算满足该档；`0` 表示该指标不参与本档判定。

**具体数字以管理后台 → 论坛管理 → 信任等级页显示的当前值为准。** 该页有「恢复推荐默认」按钮，点了就能
看到内置推荐值。本页不复制数字：阈值是可配置的，抄一份到文档里迟早与站点实际值分叉，而且
分叉后不会有人发现。

TL0 不参与判定，它的行为限制由「新人限制」那七项决定（见下一节）。

**账龄闸**：注册不满「新人信任期」天数时最高只到 TL1——活动量足够可以提前离开 TL0，
但不能提前越过 TL1。这个天数就是「新人限制」里的信任期，两处是同一个值。

**关于限额**：站点默认的发帖冷却与日限额都是 `0`（不额外限制），所以 TL1 及以上各档之间
今天**没有可观测的限额差异**；「高等级免冷却」这类说法在本仓库不成立，本页不写。

## 增加、减少与插序

入口：**管理后台 → 论坛管理 → 信任等级 → 「档位管理」分区**。页面会显示「启用 {count} / {max} 档」，
`{max}` 就是 8：档数只能在 1–8 之间。

- **加档**：点「新增一档」，新档加到末尾；要在中间就点「在此档前插入一档」，或者事后用
  「上移一档」/「下移一档」调整顺序。
- **新档的三个默认**：门槛从 `0` 起（`0` 表示该指标不参与本档判定）；限额留空表示沿用站点默认；
  可解锁清单为空。
- **插序不会改动任何已有档位已经配好的门槛、限额与解锁清单。** 配置跟着档位自己走，
  不跟着它的位次：在某一档前面插入一档之后，原来那一档仍然是原来那一档，只是序号变了
  （TL 编号随之重排）。
- **减少档数不是删除档位。** 没有「物理删除」这个动作，减档走「停用」，见下一节。
- **保存后所有人按新阶梯重新判定。** 等级本来就每次请求重算，所以插档、减档都不需要数据
  迁移、不需要回填，也不用等什么任务跑完。

## 停用与恢复

- **停用是软停用**：在某档上点「停用」，该档显示为「已停用」。它的门槛、限额、解锁清单
  **原样保留**，判定与展示跳过它；点「恢复」即按原顺序回到原位次。
- **停用可能让人降权。** 保存前的确认框是「确认停用「{name}」？」并列出
  「可能被撤回的解锁：{keys}」——那就是这档贡献、可能从用户身上撤回的能力。**如果其它启用档
  已经覆盖了它的全部解锁，确认框会直接写「预计不会撤回任何能力」**，那就只是顺序变化，
  不会有人掉能力。
- **最后一档不能停用。** 页面会写「至少保留一档，最后一档不能停用」，并且那个「停用」
  按钮直接不可用——不是等你保存后才报错。
- 只剩 1 档时，新人信任期的账龄闸不再产生任何差异（只有一档可判），后台会常驻提示这个后果。
- 停用与恢复都只改表单，**以页脚那一次保存为准**；不点保存不会写库。

## 命名与图标

- 每档两个名字：「中文名」与「English name」，都自由填写。**存的就是你填的名字**；
  「命名建议」只是把备选名一键填进去的快捷方式，填了之后仍然可以改、也可以清空重填。
- **显示回退顺序**：当前语言的名字 → 另一种语言的名字 → 内置默认名（默认那几档才有）→
  `TL{序号}`。英文名留空，英文站会显示中文名，后台会提示这一点。
- **图标**点「图标」从后台给出的白名单里选。不选时按位次取默认序列，后台会提示
  「未选图标时按位次取默认序列：{icons}」并把实际序列列出来——本页不抄这份清单（会漂移），
  要看就以页面显示为准；默认站点前三档依次是芽、叶、屋。
- 改名与换图标**不触发重新判定，也不改任何权限**：名字和图标是展示，不是身份。

## 今天就能调：新人限制（七项）

入口：**管理后台 → 设置 → 「新人限制」标签**（设置页的固定标签之一，图标是幼苗）。

这一页今天就是 TL0 的全部内容，也是信任等级接线后 TL0 的唯一数值来源。

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| 新人信任期（天） | 7 | 从注册日起算。`0` 表示不启用新人限制 |
| 新人发帖冷却（秒） | 300 | `0` 表示不额外限制 |
| 新人评论冷却（秒） | 60 | `0` 表示不额外限制 |
| 新人每日发帖上限 | 3 | `0` 表示不额外限制 |
| 新人每日评论上限 | 30 | `0` 表示不额外限制 |
| 禁止新人外链 | 开 | 信任期内含 http(s) 外链的帖子/评论被拒绝 |
| 禁止新人附件 | 关 | **当前不生效**，见下方提示 |

「`0` 表示不额外限制」只解除**这一项**，论坛全局的冷却与限额仍然生效。

> **已知问题：「禁止新人附件」当前不生效。** 这个值会被保存、也会在后台显示，但发帖
> 与上传链路没有读取它，勾选与否行为一致。需要禁止附件请用附件自身的上传策略。这一点
> 已在模块笔记里登记，不要当成配置没保存。

**三类账号不进入新人限制**（这是设计内行为，不是漏洞）：

- 具备 `settings.manage` 或 `topic.edit_any` 的用户——否则版主和管理员会被自己的站点
  拦在门外；
- 机器人账号（AI 回复等）——它没有登录凭据，另有 AI 配额与审核闸门约束；
- 把信任期设为 `0` 时的全部用户。

## 怎么调等级阈值

入口：**管理后台 → 论坛管理 → 信任等级 → 「门槛设置」分区**。每档一列 × 六指标
（访问天数、主题数、回复数、获赞数、给赞数、收藏数），`0` 表示该指标不参与本档判定。
档数由「档位管理」决定，这里跟着变。TL0 在这里是只读的，页面提示原文：TL0 由「新人限制」页决定，此处只读。

**保存后即时生效：等级与限额都会按新阈值重算。** 等级判定与发言限额是同一条链路，不再
拆成两半——调高某档门槛，未达标的用户会降档；调低门槛，达标的用户会升档。

**能力解锁在同一页，默认关闭。** 见下一节——清单默认空集，所以**勾选**这件事在默认安装里
不改变任何人的能力。注意区分：等级本身仍会通过基线门改变 TL0 的两个键（上一节），那与勾选无关。

## 开启能力解锁（earnable）

入口：**管理后台 → 论坛管理 → 信任等级 → 「能力解锁」分区**（与门槛设置同一页），按档勾选可解锁的权限键。

**默认全空，这是正常态。** 默认安装下每一档的 earnable 清单都是空的；等级对能力的唯一默认影响
是上一节的基线门（TL0 少两个键）。默认的 `member` 角色本来就持有全部 7 个可解锁的键，所以
**只开清单、不动角色**，不会有任何人的能力**因为勾选**发生变化——要看到勾选效果，得同时把
该键从对应角色里拿掉（那是角色管理页的事，不在信任等级页）。可解锁范围与「以下永远不可解锁」
的边界见上一节。

三条必须知道的口径：

**一、勾选是累积的。** 勾选某一档的某个键 = 该档**及以上**全部解锁。给第 2 档勾「发主题」
之后，第 3 档及以上也一并拥有它（下面用默认五档的编号举例；档位可增删，编号会随之变化）。
所以清单按「该档**新增**」理解，不是「该档拥有」；只想给最高档，就只给最高档勾。

**二、TL0 不参与 earnable。** TL0 的行为限制由「新人限制」七项决定，可解锁清单对 TL0 不生效；
但 TL0 仍受基线门影响（少两个键），两者不是一回事。

**三、阈值全 0 等于「人人达标」。** 判定是「所有指标同时达到」才算满足该档，而 `0` 表示
该指标不参与判定。把某一档的指标全部填 `0`，等于**所有用户都满足这一档**——零活动账号会
直接落进该档，并拿到该档累积的全部可解锁权限。这是构造上的必然，不是 bug：`0` 是
「不参与判定」，不是「不启用这一档」。（账龄闸仍然生效：新人信任期内的账号最高只到 TL1。）

保存后即时生效。取消勾选某个键，对应等级的已挣得能力在下一次请求装载时消失；等级本身
不会因为取消勾选而下降。

## 怎么恢复默认

**恢复推荐默认 = 整份配置回退，不是「只重置阈值」。** 点「**恢复推荐默认**」会让服务端把
**整份档位配置**换回推荐默认：档位数量与顺序、每档阈值、每档限额、各档新增的能力解锁、
档位名称与图标，全部回退，**已停用的档位会被移除**。页面常驻说明原文：
「恢复默认会由服务端把整份档位配置（档位、阈值、限额、能力解锁、名称与图标）重置为推荐默认；
用户的等级会按新配置重新判定，已获得的徽章与已发布的内容不受影响。」

这是**破坏性动作**：执行前会弹**阻塞式确认**，确认框里逐项列出会丢掉哪些手工配置
（同样是这五类），确认后立即生效，全站按新阶梯重新判定。只想改某一项时，请到对应分区
直接编辑并保存，不要用恢复默认。

**新人限制：** 点「**恢复新人推荐默认值**」，确认后表单填回推荐值，同样**仍需点保存**才
落库。推荐值就是上表的默认值。

## 常见疑问

**后台用户详情里看不到等级带来的权限，是不是漏了？** 不是。用户详情展示的是「授予了
什么」——角色与用户级覆盖；它**刻意不包含**信任等级挣得的能力。「现在能做什么」只能由
实际请求时的权限裁决回答。所以别拿后台截图当证据说「他没这个权限怎么发的帖」。

**已知缺口（照实说）**：用户详情也不反映基线门的扣除，所以 TL0 用户的详情页仍会显示他能发
主题，而实际请求会被拒。以实际请求为准，别以详情页为准。

**版主为什么不受新人限制？** 见上面三类账号：具备 `settings.manage` 或 `topic.edit_any`
的用户被排除在外。

**把新人信任期设为 0 会怎样？** 新人限制整体不启用，所有用户按站点默认冷却与日限额
发帖；不会删除任何已有配置值。

**新人发帖被拒，提示外链？** 「禁止新人外链」开着，且该用户仍在信任期内。要么等信任
期结束，要么关掉这一项。

**信任等级会不会让我现在的角色权限失效？** 基本不会，但有一个例外。它只**加**能力，不能减；
唯一的减法是 TL0 阶段的基线门（发主题、上传附件），TL1 起自动恢复；另外停用某一档会撤回
该档贡献的可解锁能力。角色与用户级拒绝覆盖（deny）的既有语义不变。

**能不能让高等级解锁「编辑他人帖子」？** 不能。那类权限永不可挣得，后台也勾不到；原因
是它们有特权却没有对应审计。

## 对外行为

两条值得知道：

- **等级查询接口不返回限额**。公开响应只有等级与指标进度，不含每档的冷却与日限额——那等于
  把限流参数摊开给所有人。限额只在后台读面出现。
- **资料页等级卡对他人只公开档位**。别人的资料页上看得到等级，看不到进度与瓶颈：瓶颈可能
  落在「给赞数」或「收藏数」，而这两个计数不公开。只有看自己的资料页才会多出进度条。
