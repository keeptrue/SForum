## 产品原则（运营侧）

1. **推荐默认值优先**：多数设置开箱可用，支持一键恢复推荐配置。  
2. **权限以后端为准**：隐藏按钮只是体验，API 策略才是权威。  
3. **插件优先**：邮件传输、可选搜索引擎、存储厂商等走扩展，而不是改核心。  
4. **可审计**：启用可执行插件需要超级管理员的精确制品信任确认。
