## 2. DB CHECK 正则逐字对照

迁移原文（`apps/api/database/migrations/202611120002_badge_rules.sql`）：

```sql
71:  fact_key TEXT NOT NULL CHECK (fact_key ~ '^[a-z0-9][a-z0-9._-]{1,120}$'),
72:  variant  TEXT NOT NULL DEFAULT '',
92:  fact_key TEXT NOT NULL,          -- user_fact_counters 无 CHECK
```

| 位置 | 逐字符常量 | 说明 |
| --- | --- | --- |
| DB CHECK | `^[a-z0-9][a-z0-9._-]{1,120}$` | 事实行插入时强制 |
| Go 正则 | `` regexp.MustCompile(`^[a-z0-9][a-z0-9._-]{1,120}$`) `` | **零反斜杠**，raw string 与 DB 原文逐字符相同，不需要任何转义 |
| JSON Schema | `"pattern": "^[a-z0-9][a-z0-9._-]{1,120}$"` | **同样零反斜杠**。spec §1.2 那句「`\\` 要双写」对这条 pattern 不适用：`.` 与 `-` 都在字符类内且 `-` 在末尾，都是字面量。写成 `\\.` 会变成「反斜杠或点」，把合法 key 拒掉 |
| variant 校验 | schema `"pattern": "^[a-z0-9][a-z0-9._-]{0,63}$"`（1–64） | DB 侧 `variant` **无 CHECK**（`:72`），所以 manifest 是唯一收口处；`''` 表示无 variant，故 `variants[].value` 必须非空 |

长度三方对照（见 §0-E）：

| 关口 | 允许长度 | 证据 |
| --- | --- | --- |
| DB `badge_facts.fact_key` | 2–121 | 迁移 `:71` |
| schema `badgeConditions[].key` | 2–121 | spec §1.2 `minLength 2 / maxLength 121` |
| Go `versionedID` | **2–81** | `v3_validate.go:49-51` → `manifestIDPattern`（`manifest.go:65`，`^[a-z0-9][a-z0-9._-]{1,80}$`） |

越界时只有 `badge_facts` 插入会炸（`:71`）；`user_fact_counters.fact_key` 无 CHECK（`:92`），所以「累计写进去了、窗口永远少一行」这种半死态在 DB 层不设防。

## 3. `contractVersion == key@N` 要加在哪

现状：

| 位置 | 内容 |
| --- | --- |
| `v3_validate.go:15` | `contractVersionPattern = regexp.MustCompile("^[a-z0-9][a-z0-9._-]*@[1-9][0-9]*$")` |
| `v3_validate.go:49-60` | `versionedID` = pattern + `<manifest.id>.` 前缀 + `v.ids` 跨 family 唯一。**不校验等式** |
| `v3_validate.go:426-427` | `validContractVersion` = 长度 ≤ `ContractVersionMaximumLength`（`manifest.go:51` = 256）+ pattern |

既有同类强制（可直接照抄的写法）三处，都是 `ID+"@1"`：

```go
// v3_validate_platform.go:100-104（aiTools）
if declaration.ContractVersion != declaration.ID+"@1" {
    return fmt.Errorf("%w: v3 aitools rule #5", ErrInvalidManifest)
}
```

落点：新文件 `v3_badge_conditions.go` 里，在 `v.versionedID(...)` **之前**判等式（先等式再占号，避免失败后污染 `v.ids`）。取 `@N` 部分需要自己切：**仓内没有 `versionDigits` 这类 helper**（`rg versionDigits` 零命中），用 `strings.LastIndex(contractVersion, "@")` 或直接复算 pattern 分组。
